# Planificador de Torneos de Fútbol

Aplicación web simple (HTML/CSS/JS) para organizar torneos de fútbol.

## Funcionalidades

- Crear torneo con nombre, formato y fecha de inicio.
- Agregar/quitar equipos.
- Generar partidos para:
  - **Liga (todos contra todos)**.
  - **Eliminación directa** (usa la potencia de 2 más cercana hacia abajo).
- Guardar y cargar datos con `localStorage`.
- Exportar la planificación a JSON.

## Uso

1. Abre `index.html` en tu navegador.
2. Completa el nombre y la fecha de inicio.
3. Agrega equipos.
4. Haz clic en **Generar calendario**.
5. Opcional: guarda, carga o exporta tu torneo.
